# outputs/

Generated artifacts go here. Fill this folder by either:

1. Copying your local `outputs\` from the run, or
2. Running the two commands in the root README from inside the repo
   (with your `.env` present).

Expected files: nodes.json/csv, edges.json/csv, graph.html, graph.dot,
iocs.stix.json, iocs.misp.json, run_manifest.json.
