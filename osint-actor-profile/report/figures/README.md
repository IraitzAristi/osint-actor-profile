# Figures

Three views of the same reconstructed topology. Use each where it fits best.

| File | What it is | Use it as | Status |
| --- | --- | --- | --- |
| `topology_drawio.svg` | Hand-drawn topology (draw.io), icons for IP/domain, dotted line = context | **Hero figure** (README, report cover). SVG keeps the icons and is already typo-fixed. | ✅ fixed |
| `topology_drawio.drawio` | Editable draw.io source (typo-fixed) | Open in draw.io to edit / re-export a clean PNG | ✅ fixed |
| `topology_drawio.png` | draw.io PNG export (icons) | Only if you need PNG; **still shows `comunicates_with`** — re-export from the fixed `.drawio` to clean it | ⚠️ typo |
| `topology_graphviz.svg` / `.png` / `.dot` | Auto-generated by `build_report_artifacts.py` | In the report next to the pipeline explanation, caption "auto-generated by the tool" | ✅ |
| `topology_maltego.png` | Graph imported into Maltego CE | In the report's tooling/methodology section, caption "imported into Maltego CE" | ✅ fixed |
| `topology_maltego.mtgl` | Maltego graph source | Open in Maltego to reproduce the view | ✅ |

The story these tell together: **you designed the topology (draw.io), your tool
generates it automatically (Graphviz), and you can take it into a standard OSINT
platform (Maltego).** Three angles on the same graph.

To finish `topology_drawio.png`: open `topology_drawio.drawio` in draw.io and
File → Export as → PNG. (The `.svg` is already clean if you prefer vector.)
